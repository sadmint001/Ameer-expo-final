# Ameer Expo Africa & Middle East 2026

This project is the official web application and registration portal for the **Ameer Expo Africa & Middle East 2026** — the premier business, trade, and innovation summit taking place at the Sarit Expo Centre in Nairobi, Kenya, from September 18-20, 2026.

## What this project does

The platform serves two primary purposes:

1. **Event Information Hub**: A landing page providing details about the expo, why to attend, event schedules, exhibitor & sponsor information, and FAQs.
2. **Comprehensive Registration System**: A seamless 6-step registration flow for attendees, delegates, and VIPs. The system captures:
   - Personal and professional details
   - Business types and industries
   - Networking targets and B2B interests
   - Logistics (Hotel, Visa assistance, Airport pickup)
   - Draft persistence (auto-saves progress so users can resume later)

## Tech Stack

The application is built with a modern React stack optimized for performance and type safety:

- **Framework**: [TanStack Start](https://tanstack.com/start) & [React](https://react.dev/)
- **Routing**: [TanStack Router](https://tanstack.com/router)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **UI Components**: [shadcn/ui](https://ui.shadcn.com/) (built on Radix UI)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Build Tool**: [Vite](https://vitejs.dev/)

## Development

To run the project locally, ensure you have Node.js and npm (or bun) installed.

```sh
# Install dependencies
npm install

# Start the development server
npm run dev

# Build for production
npm run build
```
